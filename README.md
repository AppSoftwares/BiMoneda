BiMoneda es un proveedor de software de facturación para condominios.
No procesa pagos, no custodia fondos de terceros ni tiene acceso operativo a cuentas;
solo emite recibos después de que el administrador valida el pago, y lleva
un registro de operaciones P2P que el propio usuario reporta. Bajo el
artículo 9 de la LOCDOFT y la Providencia ONCDOFT-002-2021 (RUSO), un
proveedor de software con ese perfil no encaja como "sujeto obligado".
El objetivo de estos cambios es dejar eso documentado dentro de la
propia app: quien firma y presenta cada documento es el usuario, no
BiMoneda.
