1. ARQUITECTURA: DECISIÓN DE BASE DE CÓDIGO
================================================================
Se recomienda ELIMINAR la carpeta 'app/' (Kotlin Nativo) y mantener únicamente
la base de código React + Capacitor (src/, android/, ios/).
Riesgo: Mantener ambas genera inconsistencias legales en el cálculo de impuestos.

3. CÁLCULO DE IGTF (Venezuela)
================================================================
Se ha identificado que el IGTF no se calcula automáticamente. Se sugiere aplicar:
